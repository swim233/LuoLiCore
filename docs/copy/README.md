# 文案改写

WebUI 这一侧**用户看得见的每一句话**，在真界面上逐句改，按保存写回源码。工具在 `scripts/copy/`。

这里**不是** i18n 层：源码始终是唯一真相，面板只在改写期间存在。

```bash
pnpm dev                        # 服务端（WebUI 的 /api 要它）
COPY_EDIT=1 pnpm webui:dev      # 带文案面板的 dev server
pnpm copy:stats                 # 只数数：现在一共有多少字要管、多少条被钉住
```

打开 http://localhost:5173，页面上浮起一扇「校样」窗。

## 这扇窗

**浮窗，拖标题栏移动，拖右下角改尺寸**，位置与尺寸记在 localStorage（重载回到原处）。
标题栏上的 `⇥` 一键**贴回右侧**（占满右边一条、不遮挡页面），`⇱` 再脱开成浮窗 ——
改排版时要看见页面全貌，改文案时浮着更近手。

- 只有**标题栏与右下角把手**能起手拖。内容区不行：面板本身还有一个「拖动页面元素」模式，
  两种拖拽从同一个地方起手必然误触。
- 存下来的位置每次都会**收进视口**再用（换屏幕、缩窗口之后，旧坐标可能整个在视野之外 ——
  那时面板等于消失了）。

列表里一条一行，**点开哪条才展开哪条的控件**：八组档位一次全铺出来，一条要占半屏。

左边一道贯穿的沟槽，行号坐在上面 —— 那是**源码行号**，面板里的一条与编辑器里的一行是同一个坐标。
页边那道竖线是改动标记：琥珀 = 有未保存的改动，白 = 当前选中。

**选中那一条的预览用它在页面上真实的计算样式渲染**（字体、字号、字重、字距全抄过来，字号收在
11–30px 之间免得撑破面板）。这是整扇窗存在的理由：在 13px 通用无衬线里判断不了一个 `.68rem`
抬头的字距对不对；改字号 / 字重时预览跟着变，**看到的就是保存后的样子**。

## 暂存与撤销

**一切改动都只是暂存。** 改文案走内存覆盖层，版式 / 偏移 / 隐藏 / 删除走 DOM 预览 ——
**源码一个字节都不动，直到按〔保存〕**。那一刻所有暂存改动一次写完。

- 〔撤销〕/ **Ctrl/Cmd+Z** 逐步退未保存的改动。连续打字并成一步，不会一次退一个字符；
  输入框里按 Ctrl+Z 不拦 —— 那时人要的是退掉刚打的字符，交给浏览器。
- 〔全部丢弃〕清掉全部未保存的改动。
- 〔历史 N〕是**已保存的那些**：每次保存存一层，点任意一层「退到这之前」。见下面「保存历史」。
- **保存被拒的那几条会留在面板上**，字不会丢。落盘侧除了给人看的那句话，还交回**没落地的目标**
  （`stuck`）—— 只凭前者，面板认不出该留哪几条，就只能全清，而那正是「拒绝 3 处」之后人刚打的
  三句凭空消失的成因。被删除范围吃掉的不算「没落地」（那些本来就没意义了）。
- **退历史之前会先丢掉未保存的**：退完源码是另一份，留着的暂存态记的 offset 与元素 key 全是旧的，
  下一次保存会被整批拒 —— 而「按了保存什么都没发生」最难看懂。

**文案按条目记，版式按元素记。** 185 个元素被两条以上文案共用（472 条，比如
`<p>{{ a }} 步 · {{ b }} 次</p>`）—— 版式按条目记的话，在 A 行点了隐藏，B 行的按钮仍显示未选中，
两行都点过之后保存时的合并顺序决定结果。所以贴边 / 字号 / 偏移 / 隐藏 / 删除的暂存键是**元素**。

为什么一次写完而不是逐条：所有 offset 都是对着**同一份原文**量的。逐条写盘的话，第一条写完后面
所有 offset（以及元素 key）就全漂了，第二条要么找不着位置、要么切错地方。`applyChanges` 是
**全仓唯一的写入口**，`tests/copy-edit.test.ts` 断言「保存前源码一个字节都没动」。

**条目 id 是 12 位十六进制，不许收窄。** 取的是 `sha1(file, raw, nth)` 的前 12 位 —— 用
`(file, raw, nth)` 而不是 `(file, offset)` 是为了让 id 跨一次保存活下来（offset 每次保存都变，
而面板的 `store.overrides[id]` 要活到下一次扫描）。位数是安全边界不是审美：`applyChanges` 里
`new Map([id, entry])` 撞号时静默留下后写入的那条，而两条 entry 的 offset 指着源码里完全不同的
两段，**于是在面板里改 A、被改写的是 B，而 A 原文还在**。6 位是 24 bit，本仓 2700 条文案下撞号
概率约 **20%** —— 而它真撞过（`aa826d`：`sandbox.bypassRoles` 与 `approval.skipForOwner` 两条
配置说明）。12 位下同样规模约 1.3e-8，再加一道 `duplicateIds()` 兜底：真撞上时那条改动一律
**拒绝**并留在面板上，不猜是哪一条（「摘除比伪造安全」）。

同一个元素上的多处改动（字号 + 字重、偏移 + 字号基准）**先折成一份最终值再落一次刀**：
各算一次的话第二条是拿已经过期的旧值算的，落刀时又指向同一段源码 —— 要么被判重叠丢掉，
要么在元素上插出两个 `class` 属性。

## 保存历史

每次〔保存〕之前的那一份源码存一层，落在 `.luoli-copy-history/`（已被 `.gitignore` 的 `.luoli-*`
盖住，本机产物不进版本库），**留最近 20 层**，再往前是 git 的事。

- 「退到这之前」= 把那一层**及其之后**碰过的每个文件写回那一层之前的样子。一个文件在三层里都被
  改过时，写回的是**最早那一份** —— 取最新那份等于什么都没退。
- 退完那些层就删掉：它们描述的世界已经不存在了，留着会让第二次点退到一个从未存在过的混合状态。
- 落盘而不是留在内存里：dev server 一天重启十几次（改 `vite.config.ts`、改插件都会重启），
  只在内存里的历史那时就空了，而人对「历史」的期待恰恰是它比进程活得久。

没有历史时按钮是灰的，不会假装退了一步。

## 改文案

- **本屏出现的** —— 这一屏**真的渲染过**的每一句，新出现的排在最前。切一页过去，那一页的文案就浮到顶上。
  收集靠渲染期插桩而不是扫 DOM：`title` / `aria-label` / `placeholder` 与 toast 的字都不在 DOM 文本里。
- 输入即时生效，左边真界面立刻变 —— 看得见字长、换行、密度对不对。
- **带占位符的那 246 条**（全仓 2533 条里）见下一节。
- `钉住` 标着这句同时被 `docs/09` 的「」引用或某条测试断言引着。照常改，落回之后那两处要人跟一遍。

## 带占位符的文案

模板正文里是 `{{ n }}`，字符串 / 模板串里是 `${n}`。面板里那一条会把它们摊成一排小牌子，
**先看清有什么必须留着，再动手改**。

- **预览填真值。** 改 `共 {{ n }} 条` → `一共 {{ n }} 回`，页面上显示的是「一共 42 回」而不是
  字面的 `{{ n }}`。做法是插桩时把占位的表达式按源码顺序再传一份给运行时
  （`__LUOLI_C__('id', \`共 ${n} 条\`, [n])`），运行时按占位**文本**换回去 —— 所以把占位挪到
  句首、或者一句里出现两次，都还对。
  代价是那些表达式**求值两次**；这里的表达式全是取值/格式化，没有副作用。
- **位置随便挪，个数不能少。** 判据是**个数**而不是「在不在」：
  `删除 ${name} 的配置覆盖？…回到 agents/${name}.md` 只留一个的话，第二处会变成字面的
  `agents/.md`，而「在不在」检查不出来。少了就整条拒绝落回并在面板上划掉那个牌子。
- **大括号内侧的空白会顺手收齐**：`{{n}}` / `{{  n  }}` 都算同一个占位，落盘写成记录里那个样子
  （不然源码里会攒出四种写法）。**表达式内部一个字都不动** —— 改表达式是改代码。
- **嵌套的占位按括号数**：`` `恒发「${list[i]}」${i === raw ? '' : `（下标 ${raw} 越界）`}` ``
  第二个占位自己就带一层 `${}`。这里原先用的是 `\$\{[^}]*\}`，切出来是残句 —— 拿它做「在不在」
  的检查还看不出问题，一旦拿它生成代码就当场把 4 个文件切坏（实测）。
- **两条例外**（面板里照常改得动、存得下，只是预览显示字面占位）：`${env:NAME}` 这种**散文里的**
  美元花括号（它不是表达式，没有值可填）；以及少数 `{{ }}` 里嵌着模板串的，插桩时补上值会让
  Vue 的插值提前收尾，那时宁可不补。判据是 `new Function` 真解析一遍那串表达式，切歪了就退回。
- 服务端产的那些（`apiError`、配置说明）本来就没有即时预览，改与存不受影响。

判据只有一份（`scripts/copy/slots.ts`），面板与落盘共用 —— 各写一份的必然结果是按钮亮着而保存被拒。

## 点界面上的字，跳到那一条

开〔点选〕之后在界面上点任意一句，面板就滚到对应条目、高亮、输入框拿到焦点（**Alt+点击** 随时可用，
不必先开模式；Esc 退出）。点选模式下那一下点击会被拦住 —— 不拦的话会顺带触发按钮、切页、提交表单。

实现是给带文案的元素挂 `data-copy-id` 属性，**不是包一层 span**：`styles.css` 里有 12 处 `+ .`
相邻选择器、8 处 `:nth-child`、4 处 `:last-child`，多套一层元素会把布局改掉，加个属性不会。
点到没有登记在册的地方（图标、纯数字）会明说，不装作找到了。

反方向也有：悬停面板里的一条，会把界面上那句圈出来并滚过去。

## 自由拖拽定位

开〔拖动〕，在界面上**按住任意一句话直接拖**。按住 Shift 锁定单轴（只想水平挪时，手不稳会带出
几像素竖直偏移）。松手只是暂存，面板上那一条会显示当前偏移，旁边还有：

```
0, 0   [←] [↑] [↓] [→] [归位]      ← 方向键微调 1px，按住 Shift 为 10px
```

偏移落成元素自己的 `style="translate: 12px -4px"`。

- **为什么是独立的 `translate` 属性而不是 `transform`**：`styles.css` 里 16 处 `transform: translate`、
  10 处 `scale`、3 处 `rotate` —— 按钮按压反馈（`scale(.97)`）、入场动画（`rise-in`）、页面过渡都在用
  `transform`。写内联 `transform` 会把它们整条顶掉；`translate` 是独立变换属性，与 `transform`
  **叠加**而不是互斥，全仓一处未用。
- **偏移是固定像素。** 这套界面有响应式断点，换个宽度它还偏这么多 —— 小幅微调正是想要的效果，
  大幅位移则会在别的宽度下错位。这一点是明知代价的选择，不是疏漏。
- 元素被推出容器时不会撑开布局（`translate` 不参与排版），所以可能与邻居重叠 —— 这也是「自由」的代价。
- 归位 = 清掉这条声明；连整个 `style` 属性一起摘走，不留 `style=""`。

## 字号 / 字重 / 斜体

```
字号 [更小] [小] [大] [更大]   斜体 [斜] [正]
字重 [常规] [中] [半粗] [粗]
```

档位落在**带 `data-copy-id` 的那个元素**上，也就是整个 `<p>`、整个 `<h1>`。想给一句话里的两个字
加粗要往模板里插 `<strong>`，那是结构改动，这套工具不做（原因见「覆盖不到的」）。

- **字号是「基准 × 倍数」**，不是绝对值也不是父级相对。倍数由 class 定（.85 / .92 / 1.12 / 1.3），
  基准由面板量一次元素**自己**的字号、写成内联 `--u-base`。
  为什么不能直接写 `font-size: 1.12em`：`em` 在 `font-size` 上是**父级**的字号 —— 实测这个界面上
  一个 64px 的 `<h1>`（父级 16px）点「大」会缩到 17.9px，与按钮上写的字正好相反。而 CSS 里没有
  任何单位能表达「我自己现在这么大的 1.12 倍」，所以基准必须存下来。
  存下来还有一个好处：点两次不叠加（倍数是替换的），四个档位不会随点击次数漂走。
- **中文没有真斜体**，浏览器是把字倾斜画出来的（synthetic oblique），落在正文上通常难看 ——
  给英文抬头（`.eyebrow` 那类）用是合适的。`正` 那一档留给「把继承来的斜体掰正」。
- **不给颜色**。颜色承载状态语义（危险 / 主次 / 禁用），逐句改颜色会让同一个红色在两处意思不同。

## 隐藏 / 删除

```
结构 [隐藏]                                    [删除…]
```

两件不同的事，所以是两个按钮：

- **隐藏**写一个 `u-display-none` token，一秒可逆，随 CSS 正常发布。「先藏起来看看」用它。
- **删除**真的把元素从模板里摘走 —— 带二次确认，且**连带几条文案会写在按钮上**（删一个 `<p>` 和
  删一个装着 14 句话的 `<section>` 在界面上长得一模一样，而后者按下去是一大片）。
  整行只有这个元素时连缩进与行尾换行一起摘掉，不留空白行。

**三条否决判据，命中即不许删**（面板把理由原样显示出来，而不是灰掉一个按钮）：

| 判据 | 为什么 | 全仓命中 |
|---|---|---|
| 后面紧跟着 `v-else` / `v-else-if` | 删掉前面那个 `v-if`，紧跟的 `v-else` 当场是**编译错误** —— 整页白屏，而且是保存之后才发生 | 81 处 |
| 带 `ref` | 脚本里 `xxx.value!.focus()` 这类写法会在运行时炸 | 8 处 |
| 模板唯一的根节点 | 组件从此渲染不出任何东西 | 22 处 |

删除的预览是**真的看不见**（不是打个叉）：删掉一个 flex 子元素会让旁边几个重新排，而那正是
按下保存之前唯一需要看清的东西。面板上那一行仍在，随时〔取消删除〕。

删除范围里的其它暂存改动会被**吃掉**（同一元素里的一句文案、它自己的档位）—— 那些改动已经没有
意义了，计数也跟着扣回来：删一个容器 + 改它里面一句话 = 一处，不是两处。

## 贴边 / 对齐 / 间距

```
贴边  [靠左] [居中] [靠右]    对齐 [左] [中] [右]
上间距 [无] [窄] [宽] [更宽]        ← 横排容器里显示成「左间距」
```

- **贴边** = 元素在容器里贴哪边（flex/grid item 的 `margin-inline` auto）；**对齐** = 文字在自己框里怎么对齐
  （`text-align`）。两件不同的事，所以是两组控件。方向按**真实容器的 computed style** 判：
  `styles.css` 里 86 处 flex + 95 处 grid、只有 5 处 `column`，横排容器里「与上一块的距离」是水平的。
- 点已经选中的那一档就是取消。
- 做法是往模板的 `class` 里写一个 `u-*` token（工具层在 `styles.css` 末尾，规格见 [09 §6](../09-webui.md)）。
  预览是先在 DOM 上切 class —— 走的就是同一条 CSS 规则，所以**看到的就是保存后的样子**。
- 元素原来没有 `class` 属性时会新插一个；把 token 清空时连属性一起摘走，**不留 `class=""`**
  （`tests/copy-edit.test.ts` 断言「设了再清 = 源码一个字节都没变」）。
- 间距只有四挡，**不开任意数值**：尺度一旦按句微调，两周之后这套界面的节奏就碎了。

## 不影响生产

插桩由 `scripts/copy/plugin.ts` 做，两道闩：`COPY_EDIT !== '1'` 时插件直接返回 `false`
（Vite 忽略假值插件），返回的插件又带 `apply: 'serve'`，`vite build` 阶段不参与。面板与
`__LUOLI_C__` 都在 `packages/webui/src` 之外，生产构建里没有引用路径指向它们。
`tests/copy-edit.test.ts` 焊住这三件事，并且逐个文件验证插桩后仍能被 Vue / TS 解析。

**`u-*` 工具类、拖拽偏移与 `--u-base` 不在此列** —— 它们是写进模板的正常样式，会照常发布
（工具层压缩后 474 字节）。面板自己的样式、动画、`.cp-ghost` 那条预览规则都只在 dev 注入：
实测带 `COPY_EDIT=1` 跑 `pnpm webui:build`，产物的 JS 与 CSS 里 `__LUOLI_C__` / `__copy` /
`cp-ghost` / `luoli-copy-panel` 各 0 处。

## 抽取范围

收：模板文本节点（连着的文字与插值合成一条，`总计 {{ n }} 次` 是一句而不是三截）、插值里的
字符串、`label` / `empty` / `placeholder` / `title` / `aria-label` 等一批「会被人读到」的属性、
script 里带中文的字符串与模板串。约 2530 条。

**服务端产的那 506 条也在册**（`server/src/app.ts` 的 155 处 `apiError`、
`core/src/config/descriptions.ts` 的配置说明）：在面板的「全部」里搜得到、改得动、存得下，
只是没有即时预览 —— 那些字由服务端渲染，要重启才看得见。

不收：注释、`styles.css`、纯 ASCII 的标识符/类名/路径/枚举值（`severity="secondary"`、
`pi pi-bolt`），少数属性值里带 `&#10;` 这类 HTML 实体的条目不插桩（解码后会截断 JS 字符串，
所以只在「全部」里改、没有预览），以及 **Telegram 那一侧**（bot 回给用户的话、工具的报错）——
那是另一个界面，要的话另抽一份。

有漏掉的直接说是哪一句，规则在 `scripts/copy/extract.ts` 的 `looksLikeCopy` / `COPY_ATTRS`。

## 覆盖不到的

把一句话从正文挪进 tooltip、或者搬到另一个父级里去，是语义 / 结构改动，工具不碰
（`styles.css` 大量用后代选择器，`.top-actions .search` 那种搬出去样式会直接失配）。
这类直接说要什么效果，改源码。
