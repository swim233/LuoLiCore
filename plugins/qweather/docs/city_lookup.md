# 城市查询（city_lookup）

把地名查成经纬度，同时给出它属于哪个省市、在哪个时区。

## 参数

- `location`（必填）：地名，如 `上海`、`beijing`。也可以写 `经度,纬度`（先经度后纬度，如 `116.41,39.92`），查这个坐标在什么地方。
- `adm`：上级行政区，用来排除重名，如 `location: "朝阳", adm: "北京"`。
- `range`：只在某个国家或地区里找，写 ISO 3166 的国家代码，如 `cn`。不写就在全世界找。
- `number`：返回几个结果，1 到 20，默认 10。
- `lang`：语言，见总说明。

## 返回

- `code`：`"200"` 是成功。
- `location`：查到的地方的列表，每个有：
  - `name` 名字，`id` 和风的地点编号；
  - `lat` 纬度、`lon` 经度（字符串，五位小数）；
  - `adm2` 上级行政区，`adm1` 一级行政区（省），`country` 国家；
  - `tz` 时区（如 `Asia/Shanghai`），`utcOffset` 和 UTC 差几小时，`isDst` 是不是在夏令时（`1` 是）；
  - `type` 地点的类型（如 `city`），`rank` 排名的分数，`fxLink` 这个地点的天气网页。

## 要注意

- 查中国的地名一定加上 `range: "cn"`。
- 不加 `range` 时，查不到并不报错，而是照样返回 200 和几个名字不相干的外国地点。所以拿到结果先看 `name`、`adm1`、`country` 是不是人说的那个地方，对不上就当没查到。
- 加了 `range` 又查不到时返回 HTTP 400（No Such Location）。换个写法再试一次，还不行就问人。
- 结果不止一个、分不清人说的是哪个时，把候选的 `name`、`adm2`、`adm1` 列出来问人。
- 后面的接口用这里的 `lat`、`lon`，四舍五入到两位小数。
