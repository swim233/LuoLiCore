# 城市查询（city_lookup）

把地名查成经纬度，同时返回所属的省市和时区。

## 参数

- `location`（必填）：地名，如 `上海`、`beijing`。也可以填 `经度,纬度`（先经度后纬度，如 `116.41,39.92`），查询此坐标所在的地点。
- `adm`：上级行政区，用于排除重名，如 `location: "朝阳", adm: "北京"`。
- `range`：限定在某个国家或地区内查询，填 ISO 3166 的国家代码，如 `cn`。未填写时在全球范围内查询。
- `number`：返回结果的数量，1 到 20，默认 10。
- `lang`：语言，见总说明。

## 返回

- `code`：`"200"` 表示成功。
- `location`：查询到的地点列表，每项有：
  - `name` 名称，`id` 和风天气的地点编号；
  - `lat` 纬度、`lon` 经度（字符串，五位小数）；
  - `adm2` 上级行政区，`adm1` 一级行政区（省），`country` 国家；
  - `tz` 时区（如 `Asia/Shanghai`），`utcOffset` 与 UTC 的时差（小时），`isDst` 是否处于夏令时（`1` 为是）；
  - `type` 地点的类型（如 `city`），`rank` 排名的分数，`fxLink` 此地点的天气网页。

## 注意事项

- 查询中国的地名时必须加上 `range: "cn"`。
- 未加 `range` 时，查询不到并不报错，而是照常返回 200 和几个名称无关的国外地点。因此拿到结果后先核对 `name`、`adm1`、`country` 是否为用户所说的地点，不符时视为未查到。
- 加了 `range` 仍查询不到时返回 HTTP 400（No Such Location）。换一种写法重试一次，仍不行就询问用户。
- 结果不止一个、无法判断用户指的是哪个时，列出候选的 `name`、`adm2`、`adm1` 询问用户。
- 其他接口使用此处的 `lat`、`lon`，四舍五入到两位小数。
